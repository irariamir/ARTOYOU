# ARTOYOU — دانلودر یوتیوب 🎬

سامانه شخصی و خودمیزبان برای دانلود ویدیوهای یوتیوب — لینک را بچسبان، کیفیت را انتخاب کن، تحویل بگیر.

## ✨ ویژگی‌ها

- **بازه ۵ دقیقه تا ۱ ساعت** — ویدیوهای بلند (مستند، سخنرانی، پادکست تصویری) بدون محدودیت حجم
- **همه کیفیت‌ها از 360p تا 8K** — 4320p / 2160p / 1440p / 1080p / 720p / 480p / 360p
- **ترکیب خودکار تصویر + صدا** با ffmpeg برای کیفیت‌های بالای 720p (خروجی MP4 سازگار با همه پخش‌کننده‌ها)
- **استخراج صدا** به دو صورت: **M4A اصلی** (بدون افت کیفیت) و **MP3 تا 320k**
- **نوار پیشرفت زنده** — درصد، سرعت لحظه‌ای و زمان باقی‌مانده
- **صف دانلود همزمان** با لغو، حذف و تاریخچه دانلودها
- **ضدبات یوتیوب** — پشتیبانی از کوکی مرورگر (`YT_COOKIES_FILE`)
- **کاملاً شخصی** — بدون اکانت، بدون ترکینگ؛ امکان فعال‌سازی توکن دسترسی (`ARTOYOU_TOKEN`)
- **رابط فارسی راست‌به‌چپ** با طراحی تیره و واکنش‌گرا (موبایل و دسکتاپ) — فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (OFL) به صورت محلی و بدون CDN سرو می‌شود
- **🤖 بات تلگرام** — لینک را در چت بفرست، کیفیت را از دکمه‌های Inline انتخاب کن، نوار پیشرفت زنده ببین و فایل را همانجا تحویل بگیر (با اشتراک صف دانلود با وب‌اپ)

## 🚀 اجرا

### پیش‌نیاز
- Python ≥ 3.10
- ffmpeg — **نیازی به نصب جداگانه نیست**؛ [`imageio-ffmpeg`](https://pypi.org/project/imageio-ffmpeg/) یک باینری ffmpeg همراه خودش می‌آورد (یا با `FFMPEG_LOCATION` مسیر یک ffmpeg سیستمی را بده).

### یک‌دستوره
```bash
./start.sh          # ساخت خودکار venv و نصب وابستگی‌ها + اجرا روی پورت 8000
PORT=9000 ./start.sh
```

### دستی
```bash
python3 -m venv .venv
.venv/bin/pip install -r server/requirements.txt
.venv/bin/python -m uvicorn server.main:app --host 0.0.0.0 --port 8000
```

بعد برو به: **http://localhost:8000**

## 🤖 بات تلگرام

ربات تلگرام داخل همین پردازه بالا می‌آید و **صف دانلود را با وب‌اپ به اشتراک می‌گذارد** — دانلودهای بات در «صف دانلود» وب هم دیده می‌شوند.

### راه‌اندازی (۲ دقیقه)

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده: `/newbot` ← اسم و یوزرنیم بات را بده ← **توکن** تحویل بگیر.
2. فایل `.env` را کنار `start.sh` بساز (از روی `.env.example`):
   ```bash
   cp .env.example .env
   # و توکن را داخلش بذار:
   # TELEGRAM_BOT_TOKEN=123456789:AA…
   ```
3. `./start.sh` — در لاگ باید ببینی: `Telegram bot started (polling)`
4. در تلگرام به بات خودت پیام بده و لینک ویدیوی یوتیوب را بچسبان ✅

### نحوه کار

- `/start` و `/help` — راهنما
- هر لینک یوتیوب ← بات کارت ویدیو (تامب‌نیل + عنوان + مدت + بازدید) را با منوی دکمه‌ای کیفیت می‌فرستد
- دکمه‌ها: همه کیفیت‌ها `360p → 8K` با حجم تقریبی + `🎵 MP3` / `🎵 M4A`
- پیام پیشرفت با **نوار درصدی زنده**، سرعت و دکمه «❌ لغو دانلود»
- در پایان فایل همین‌جا ارسال می‌شود (ویدیو برای mp4، آهنگ برای MP3)

### محدودیت حجم ارسال تلگرام

توی Bot API ابری تلگرام، ارسال فایل حداکثر **۵۰ مگابایت** است؛ بیشتر از آن:

| سناریو | راه‌حل |
|---|---|
| کیفیت پایین‌تر انتخاب کنی | 360p/480p اکثر فیلم‌های کوتاه زیر ۵۰MB هستند |
| فایل‌های بزرگ (مثلاً 1080p و بالاتر) | یک **Bot API محلی** راه بینداز ↖ تا **۲ گیگابایت** |

برای Bot API محلی ([telegram-bot-api](https://github.com/tdlib/telegram-bot-api)):
```bash
# مثلاً با docker:
docker run -d -p 8081:8081 -e TELEGRAM_API_ID=… -e TELEGRAM_API_HASH=… tdlib/telegram-bot-api
```
و در `.env`:
```
TELEGRAM_API_BASE_URL=http://127.0.0.1:8081
TELEGRAM_FILE_BASE_URL=http://127.0.0.1:8081
```

### 🔐 حریم خصوصی بات — اتوماتیک است!

تو پیکربندی `TELEGRAM_ALLOWED_USERS` خالی بماند، **اولین کسی که به بات پیام بدهد مالک همیشگی آن می‌شود** و برای همه‌ی بقیه قفل می‌شود — هیچ تنظیم دستی لازم نیست:

1. بات را استارت کن (`./start.sh`)
2. به بات `/start` بفرست ← می‌بینی: «😎 تو مالک این بات شدی!» (شناسه تو در `downloads/.bot_owner` ذخیره می‌شود)
3. از این لحظه هیچ‌کس دیگری حتی با پیدا کردن یوزرنیم بات هم نمی‌تواند استفاده کند — جواب هر پیام ناشناس: «⛔️ این بات خصوصی است…»

**مدیریت مالکیت:**
```bash
rm downloads/.bot_owner   # مالکیت را ریست کن — نفر بعدی که /start بزند مالک می‌شود
```

**حالت پیشرفته (چند کاربر مجاز ثابت):** `TELEGRAM_ALLOWED_USERS=id1,id2` — این حالت بر مالکیت خودکار ارجحیت دارد و هیچ فایلی ساخته نمی‌شود.

> نکته امنیتی: توکن بات مثل رمز عبور است — فقط داخل `.env` (که گیت‌ایگنور هست) نگهش دار و هرگز کامیت/به‌اشتراک نذار. اگه لو رفت، در @BotFather با `/revoke` فوراً باطلش کن.

### 🌐 دسترسی به یوتیوب/تلگرام از ایران (فیلتر)

- به VPN سیستمی وصل باشی — همه‌چیز اتوماتیک کار می‌کند.
- یا فقط یوتیوب را از پراکسی رد کن (مثل v2ray) با `YT_PROXY`:
  ```
  YT_PROXY=socks5h://127.0.0.1:10808
  ```
- تلگرام از `YT_PROXY` رد نمی‌شود؛ برای تلگرام از VPN سیستمی یا پراکسی http/https سراسری استفاده کن.

### 🔄 اجرای دائمی با systemd (پیشنهادی برای سرور/PC همیشه‌روشن)

با یک‌یوزر-سرویس، ARTOYOU بعد از هر reboot خودکار بالا می‌آید:
```bash
mkdir -p ~/.config/systemd/user
cp deploy/artoyou.service ~/.config/systemd/user/artoyou.service
nano ~/.config/systemd/user/artoyou.service   # WorkingDirectory را روی مسیر کلون خودت تنظیم کن
systemctl --user daemon-reload
systemctl --user enable --now artoyou
loginctl enable-linger $USER                   # اجرای سرویس بدون لاگین بودن
journalctl --user -u artoyou -f                # لاگ‌ها
```

## ⚙️ تنظیمات محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` / `HOST` | `8000` / `0.0.0.0` | پورت و میزبان سرور (برای `start.sh`) |
| `MIN_DURATION` | `300` | حداقل مدت ویدیو به ثانیه (۵ دقیقه) |
| `MAX_DURATION` | `3600` | حداکثر مدت ویدیو به ثانیه (۱ ساعت) |
| `ALLOW_OUT_OF_RANGE` | — | `1` = غیرفعال‌سازی محدودیت مدت |
| `MAX_CONCURRENT` | `1` | تعداد دانلودهای همزمان |
| `JOB_TTL_SECONDS` | `7200` | نگه‌داری فایل‌های آماده قبل از پاک‌سازی خودکار |
| `ARTOYOU_DOWNLOAD_DIR` | `./downloads` | مسیر ذخیره موقت |
| `ARTOYOU_TOKEN` | — | اگر تنظیم شود، همه `/api/*` ها نیازمند هدر `x-artoyou-token` (یا `?token=`) می‌شوند |
| `TELEGRAM_BOT_TOKEN` | — | توکن بات تلگرام از @BotFather؛ اگر تنظیم شود بات داخل همین پردازه بالا می‌آید |
| `TELEGRAM_ALLOWED_USERS` | — | شناسه‌های عددی مجاز (با کاما)؛ اگر خالی باشد، **اولین کاربر که به بات پیام بدهد مالک آن می‌شود** (در `downloads/.bot_owner`) |
| `TELEGRAM_API_BASE_URL` | — | آدرس Bot API محلی؛ ارسال فایل تا ۲ گیگابایت (پیش‌فرض ابری: ۵۰ مگابایت) |
| `TELEGRAM_FILE_BASE_URL` | — | آدرس دانلود فایل Bot API محلی (معمولاً همان مقدار بالاست) |
| `YT_COOKIES_FILE` | — | مسیر فایل کوکی نت‌اسکیپ برای عبور از anti-bot یوتیوب |
| `YT_PLAYER_CLIENT` | — | کلاینت‌های جایگزین یوتیوب، مثلاً `android,web` |
| `YT_PROXY` | — | پراکسی فقط برای ترافیک یوتیوب، مثلاً `socks5h://127.0.0.1:10808` |
| `FFMPEG_LOCATION` | خودکار | مسیر باینری ffmpeg |
| `SOCKET_TIMEOUT` | `30` | تایم‌اوت شبکه (ثانیه) |

### 🍪 اگر یوتیوب «Sign in to confirm you're not a bot» داد

کوکی مرورگرت را export کن و مسیرش را بده:

```bash
# با yt-dlp از کروم/فایرفاکس:
.venv/bin/yt-dlp --cookies-from-browser chrome --cookies cookies.txt "<any youtube url>" --skip-download
# یا با افزونه مرورگر «Get cookies.txt LOCALLY» و سپس:
YT_COOKIES_FILE=/path/to/cookies.txt ./start.sh
```

## 🔌 API

| روش | مسیر | توضیح |
|---|---|---|
| `GET` | `/api/health` | سلامت سرور، نسخه yt-dlp و ffmpeg، محدودیت‌ها |
| `POST` | `/api/info` | `{url}` → متادیتا + لیست کیفیت‌ها (حجم تقریبی هرکدام) |
| `POST` | `/api/download` | `{url, kind, format_id, container, label, title, thumbnail}` → `202 {job_id}` |
| `GET` | `/api/jobs` | لیست دانلودها با پیشرفت لحظه‌ای |
| `GET` | `/api/jobs/{id}` | وضعیت یک دانلود |
| `POST` | `/api/jobs/{id}/cancel` | لغو دانلود فعال |
| `DELETE` | `/api/jobs/{id}` | حذف دانلود (یا لغو اگر فعال است) |
| `GET` | `/api/jobs/{id}/file` | دریافت فایل نهایی |

## 🧪 تست‌ها

```bash
.venv/bin/pip install -r server/requirements-dev.txt
.venv/bin/python -m pytest tests/ -v
```

تست‌ها با مدیا‌ی مصنوعی (ffmpeg testsrc) و یک HTTP سرور محلی اجرا می‌شوند — نیازی به اینترنت یا اکانت یوتیوب ندارند و کل مسیر (دانلود، پیشرفت، merge با ffmpeg، استخراج MP3، سانیتایز نام فایل) را واقعی تست می‌کنند.

## ⚠️ نکات و محدودیت‌ها

- فقط لینک **ویدیوی تکی** پذیرفته می‌شود (نه پلی‌لیست، نه کانال، نه استریم زنده).
- مدت ویدیو باید بین **۵ تا ۶۰ دقیقه** باشد (با `ALLOW_OUT_OF_RANGE=1` قابل تغییر است).
- کیفیت‌های بالای 720p در یوتیوب فقط به صورت جریان جداگانه (video-only) عرضه می‌شوند و با بهترین جریان صدا با ffmpeg ترکیب می‌شوند.
- فایل‌های دانلودشده بعد از `JOB_TTL_SECONDS` (پیش‌فرض ۲ ساعت) به‌صورت خودکار پاک می‌شوند.
- استفاده شخصی/غیرتجاری. مسئولیت رعایت شرایط استفاده یوتیوب و قوانین کپی‌رایت با کاربر است.
